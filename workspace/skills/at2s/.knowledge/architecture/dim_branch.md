# dim_branch — 营业部表

## 表描述

营业部维表，含上级分公司归属，自引用层级。312 行，`org_id` 唯一，单一快照日 `20260531`。（来源：数据推测）

层级结构：`org_id`（营业部，`XX0000xxxx` 十位）→ `up_org_id`（分公司，如 `XX00000112`），营业部名称已脱敏（如 `蚌头******营业部`、`南京分公司`）。（来源：数据推测）

**DDL 已知缺陷**：`表描述.sql` 中 `up_org_id` / `up_org_name` 的 COMMENT 误写成 `org_id` / `org_name`（重复注释），实际语义以上级字段为准。（来源：用户提供文件的笔误，数据推测佐证）

## 字段

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| data_dt | varchar(8) | 日期，本表全部为 `20260531` | 用户提供 |
| org_id | varchar(50) | 营业部ID，唯一，格式 `XX00000001` | 用户提供 |
| org_name | varchar(100) | 营业部名称，脱敏 | 用户提供 |
| up_org_id | varchar(50) | 上级营业部/分公司ID，格式 `XX00000112` | 用户提供（DDL 注释笔误已修正） |
| up_org_name | varchar(100) | 上级营业部/分公司名称，如 `安徽分公司` | 用户提供（DDL 注释笔误已修正） |
