# kb-check — 知识库完整度检查

at2s 的子流程，不对外暴露。**调用时机**：用户询问知识库是否完整、问数前体检、新增数据表后确认覆盖，或需要知道该对哪些表调用 3 号 skill。

## 硬约束

- 唯一硬依赖是 at2s 技能目录下的 `.knowledge/`（当前为 `workspace/skills/at2s/.knowledge/`）。其它文件均为可选线索，缺失时跳过而非报错。
- 检查阶段纯只读。
- 补全阶段只创建缺失项，已存在的一律跳过，**绝不覆盖或删除**。
- 自动生成的占位文件带 `<!-- kb-check:placeholder -->` 标记，下次运行据此识别为内容未完成。
- 重复执行任意次数，结果一致。
- 不输出完成度百分比 —— 缺权威表清单，百分比会误导。

## 检查项注册表

新增子 skill 时只往此表加行，下面的流程不改。

| 产出物 | 来源 skill | 完整判定 | 缺失时 |
|---|---|---|---|
| `.knowledge/` 下 `architecture/`、`conventions/`、`troubleshooting/` | kb-check | 目录存在 | kb-check 补建 |
| `skills/db-access/access.md` 记录的查表方式 | 2 号（访问数据库） | 文件存在且非占位 | 提示先与用户沟通完成 2 号配置 |
| `architecture/<表名>.md` 自身描述 + `correlation.md` 里的关系 | 3 号（生成知识库） | 表既有 `<表名>.md`，又在矩阵里有非空非对角单元格 | 提示对该表调 3 号 |
| `skills/kb-refine/config.md` 自动消化配置 | 6 号（完善知识库） | —（不判缺失，仅读取当前状态） | 仅报告是否已配置自动消化 |

## 流程

### 1 扫描（只读）

- **结构**：三个目录是否存在。
- **查表方式**：`skills/db-access/access.md` 是否存在且非占位。未就绪则报告，且注明这会导致 3 号无法抽样验证。
- **自动消化**：读 `skills/kb-refine/config.md`，报告当前是否配置了自动消化（`mode=auto` 及其阈值，或未配置=手动）。只读不改。
- **集合**：
  - `S_self` = `architecture/` 下写有自身描述的表（即存在 `<表名>.md`）
  - `S_rel` = 在 `architecture/correlation.md` 的 join 矩阵里、至少有一个填了 join 字段的非对角单元格（即非空、非 `—`、非 `↖`、非 `∅`）的表
  - `S_iso` = 在矩阵里整行整列（除对角线）均为 `∅` 的表，即已确证孤立
- **线索源**（尽力而为，按序尝试，全都没有就跳过）：
  1. 任何 DDL / 建表语句文件
  2. `dataset/` 及赛题目录下的 CSV 文件名与表头
  3. 用户在对话中提过的表名

### 2 报告

按下方模板输出三份清单，然后停下等用户决定。

- 完善 = `S_self ∩ S_rel`
- 孤立 = `S_self ∩ S_iso`，已确证无关系，**不需补充**，仅列出
- 待补充 = `S_self` 中既不属于 `S_rel` 也不属于 `S_iso` 的表（矩阵里有留空未分析格），动作为调 3 号 skill
- 潜在可添加 = 线索源发现，且不在 `S_self` 中

### 3 补全（需用户同意后才执行）

- **只补结构**：创建缺失目录；为待补充及用户确认纳入的表创建带占位标记的骨架文件。
- 不写任何表知识内容，内容一律交给 3 号 skill。
- 完成后复述实际创建的路径，未创建的说明原因。

## 报告模板

```markdown
**结构**：<三个目录的存在情况，缺哪些>

**查表方式**：<已配置 / 未配置，未配置时提示先走 2 号>

**自动消化**：<已开启 auto（阈值：…）/ 未配置，当前手动>

**表**
- 完善：`表A`、`表B`
- 孤立：`表Z`（已确证无关系，无需补充）
- 待补充：`表C`（缺关系）、`表D`（缺描述）
- 潜在可添加：`表E`（来源：<线索源>）

**建议动作**：<两三条，按优先级>
```

无线索源时，"潜在可添加"一行写：未发现表结构来源，已跳过此项。

## 对 3 号 skill 的格式契约

为使 `S_self` 与 `S_rel` 可解析：

- 自身描述：每表一个 `architecture/<表名>.md`，文件名与表名一致
- 表间关系：汇总到单个 `architecture/correlation.md`，内含以表名为行列的 join 矩阵（上三角填写，对角线 `—`，下三角 `↖`，未分析留空，确证无关系填 `∅`）
- 某表整行整列（除对角线）均留空 = 待补充；均为 `∅` = 已确认孤立（不需补充）
