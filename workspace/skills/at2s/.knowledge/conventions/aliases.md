# aliases.md — 黑话/别名全局字典

> 跨表检索总入口。来源：train_1 批次 text2sql 消化（2026-08-23，用户确认）；train_4 批次增补（2026-08-24，答案对照裁决）；train_6 批次增补（2026-08-24，答案对照裁决 + 用户确认）；train_5 批次增补（2026-08-24，答案对照裁决 + 用户裁决）。各表相关条目在 `architecture/<表名>.md` 的「别名与黑话」节有意冗余存一份。

| 口语/黑话 | 库内准确值或字段 | 涉及表 |
|---|---|---|
| 科创板 | 二级分类 `dim_product.prdt_type_name = '科创板'`（PT041100，精确匹配；一级 12 类中无"科创板"；"科创板存托凭证"为另一二级分类，本数据集无交易） | dim_product |
| 钻石卡/白金卡/金卡/银卡/理财卡 | `dim_public(code_type_id='100')` 码值：钻石卡=1000001、白金卡=1000002、金卡=1000003、银卡=1000004、理财卡=1000005；1000006 明文"空"作独立等级输出不剔除 | ads_cust_info_d × dim_public |
| 交易量 | 双边成交金额 `SUM(buy_amt) + SUM(sell_amt)`，按原始行直接汇总**不去重、不滤 ccy**（股票/科创板交易实测全部 ccy='0'） | dwd_cust_tran_d |
| 盈亏 | 期末总资产 − 期初总资产 + 期间资金净流出（fin 六字段：out 三项和 − in 三项和）；总资产 = `nm_tot_aset + fc_pur_aset`；期初=20260101、期末=20260331 | dws_cust_aset_d × dws_cust_fin_d |
| 持有/资产的时点 | 默认**期末 20260331 单日时点**（非期间、非日均），除非问题明说"日均"或"各月趋势"（后者=月内全量快照 SUM，见下条） | dwd_cust_hold_d / dws_cust_aset_d |
| 日均资产 | `SUM(nm_tot_aset + fc_pur_aset) / 90`（Q1 共 90 个快照日；与 `AVG(逐日)` 达标集合等价已实测） | dws_cust_aset_d |
| 交易金额分布 | "分布"类交易金额题：按原始维度码分组（如 sys_source），`SUM(buy_amt)` 与 `SUM(sell_amt)` **分列两列**输出、不合并成一值、维度不译中文标签；与"交易量"（双边合并单值，题面问"量"时适用）显式区分（来源：答案对照裁决，train_4/57） | dwd_cust_tran_d |
| 盈亏情况/"XX情况"类 | "情况"类=**逐客户明细**输出（pty_id+指标列，order by pty_id），非全体合计单值——无筛选的"情况"按逐主体明细，"名单类必带筛选"推理不成立（来源：答案对照裁决，train_5/68：答案 486 行逐客户盈亏，单值合计判错） | dws_cust_aset_d × dws_cust_fin_d |
| 各月/月度趋势 | 按月 GROUP BY 对月内**全部日快照 SUM**（非月末单日时点、非日均；与"日均资产"同分子形态，train_5/69 答案裁决：202601=197 亿级 vs 月末时点 6 亿级判错） | dws_cust_aset_d |
| 买入过 | `buy_amt > 0`（非 buy_cnt>0——两字段存在相异怪行：实测 55 行 cnt=0&amt>0、3 行 cnt>0&amt=0，题库以金额字段为准；来源：答案对照裁决，train_5/75） | dwd_cust_tran_d |
| 以上/以下（边界词） | 孤立阈值**不含端点**："减少10%以上"=减幅>10%（期末 `<` 期初×0.9，train_5/70 答案字面佐证）；区间分段题优先保证**区间无缝衔接**（如 [50,60)+[60,) 衔接故含 60，train_1 Q2 属此例而非"以上"语义）（来源：用户裁决，2026-08-24） | 通用（阈值/分段类筛选） |
| 分档/分层标签 | 段数**照抄题面**（明示则抄，未明示则盲拍不锚定先例——用户确认，train_6/83 孤例不复制）；**量纲贴题面**：题面带"万"标签必须带"万"（'<10万'/'[10万,50万)'/'50万以上'，train_6/82 '<100000' 判错）；年龄段一律纯区间记号 '<30'/'[30,50)'/'[50,60)'/'[60,)'；边界左闭右开含端点（"X以上"含 X）；末档"X以上"答案批间不一致，不立规则（来源：答案对照裁决，train_6/82、83 + 用户确认） | ads_cust_info_d(cust_age) / dws_cust_aset_d(资产分层) |
| 名单类输出列（二分） | **客户名单**=仅 pty_id+可选度量列、不 join 姓名（train_3/42 判错教训、train_6/80 再证）；**产品名单**=prdt_name+prdt_type_name（二级分类名）+持有客户数+市值合计（train_6/88：仅 prdt_id 判错）（来源：答案对照裁决，train_6/88） | dwd_cust_hold_d × dim_product、各客户名单题 |
