# dws_cust_fin_d

> 表注释（`表描述.sql`）：**客户资金流动日事实**

## 表描述

客户资金流动日汇总，4892 行，最小的事实表。粒度「客户 × 系统来源 × 日期」，**无产品维度**。

- `data_dt` 覆盖 `20260105`–`20260331` 共 **56 个日期**，与 `dwd_cust_tran_d` 日期集合一致
- 涉及 380 个客户，100% 落在 `ads_cust_info_d` 内

六个金额字段构成 **3 组进出对**，注释已明确各自含义：

| 组 | 转入 | 转出 |
|---|---|---|
| 现金 | `cash_in` 现金转入 | `cash_out` 现金转出 |
| 证券/托管 | `tran_in` 证券转入、托管转入、转托转入 | `tran_out` 证券转出、托管转出、转托转出 |
| 指定 | `assign_in` 指定转入 | `assign_out` 撤指定转出 |

**数据实测：只有 `cash_in`/`cash_out` 有非零值，`tran_*` 与 `assign_*` 全表为 `0.0000`。**

## 字段

| 字段 | 类型 | 含义 | 来源 | 数据实测 |
|---|---|---|---|---|
| `data_dt` | varchar(8) NOT NULL | 日期 | 表描述 | 56 个日期，与交易表一致 |
| `pty_id` | varchar(32) NOT NULL | 客户号 | 表描述 | 380 个，100% 命中客户主档 |
| `sys_source` | varchar(20) NOT NULL | 系统来源：普通(nm)、信用(fc) | 表描述 | 全量 `nm`、`fc` |
| `cash_in` | numeric(20,4) | 现金转入 | 表描述 | 有非零值，整千为主 |
| `cash_out` | numeric(20,4) | 现金转出 | 表描述 | 有非零值 |
| `tran_in` | numeric(20,4) | 证券转入、托管转入、转托转入 | 表描述 | **全表为 0** |
| `tran_out` | numeric(20,4) | 证券转出、托管转出、转托转出 | 表描述 | **全表为 0** |
| `assign_in` | numeric(20,4) | 指定转入 | 表描述 | **全表为 0** |
| `assign_out` | numeric(20,4) | 撤指定转出 | 表描述 | **全表为 0** |

## 待确认

1. **`tran_*` 与 `assign_*` 全为 0**：是本批数据恰好无此类业务，还是字段已废弃？
   算「资金净流入」时当前加不加结果相同，但换一批数据结论就会变——建议按注释语义**照常计入**。
2. **能否用本表推算盈亏**（如「期末资产 − 期初资产 − 净流入」）？
   前提是本表覆盖**全部**资金进出渠道，否则残差里会混进未记录的流动。注释未说明完备性。
3. 本表 56 天与 `dws_cust_aset_d` 的 90 天不一致，做期初期末对比时要注意端点日是否存在。
