# dim_public

> 表注释（`表描述.sql`）：**标准化编码字典表**

## 表描述

全库码值字典，155 行，已全量读取。三列结构：码值、码值类型、中文描述。

**关键约定（数据实测）**：`code` 的前 3 位等于 `code_type_id`，155 行无例外。
`code` 本身全局唯一，因此仅按 `code` 关联不会错配；但**关联时仍应带上 `code_type_id`**——
一是语义明确，二是码值扩容后一旦出现跨类型重复即会串表。

## 字段

| 字段 | 类型 | 含义 | 来源 | 数据实测 |
|---|---|---|---|---|
| `code` | varchar(12) NOT NULL | 标准字典码 | 表描述 | 7 位数字，155 行全唯一，前 3 位 = `code_type_id` |
| `code_type_id` | varchar(6) NOT NULL | 标准字典码类型 | 表描述 | 3 位数字，7 种取值 |
| `describe` | varchar(50) NOT NULL | 标准字典描述 | 表描述 | 中文文本，用于筛选与展示 |
