# dws_cust_aset_d — 客户资产日汇总

## 表描述

客户资产日汇总事实表，43684 行，覆盖 **90 个交易日 `20260101`–`20260331`**，粒度 `(data_dt, pty_id)` 唯一。（来源：数据推测）

无 `sys_source` 列——普通账户与信用账户资产**拆成 4 个独立字段**而非多行。（来源：数据推测）

## 字段

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| data_dt | varchar(8) | 日期，`YYYYMMDD` 字符串 | 用户提供 |
| pty_id | varchar(32) | 客户号 | 用户提供 |
| nm_tot_aset | numeric(20,4) | 普通账户总资产 | 用户提供 |
| nm_bal | numeric(20,4) | 普通账户现金资产 | 用户提供 |
| fc_pur_aset | numeric(20,4) | 信用账户净资产 | 用户提供 |
| fc_bal | numeric(20,4) | 信用账户现金资产 | 用户提供 |

## 别名与黑话

| 口语/黑话 | 库内准确值/字段 |
|---|---|
| 资产（时点） | 默认**期末 20260331 单日**总资产 = `nm_tot_aset + fc_pur_aset`（来源：用户确认，train_1 批次）；"各月…趋势"例外见下条 |
| 日均资产 | `SUM(nm_tot_aset + fc_pur_aset) / 90`（Q1 共 90 个快照日；与 `AVG(逐日)` 达标集合等价已实测，482/487 人有完整 90 行）（来源：用户确认） |
| 各月/月度趋势 | 按月 GROUP BY 对月内**全部日快照 SUM**（非月末单日时点、非日均；来源：答案对照裁决，train_5/69：202601=197 亿级 vs 月末时点 6 亿级判错） |
| 两时点对比基数 | 以**题面语义基准时点**的客户全集为驱动、另一端 LEFT JOIN 缺失按 0、不取两端点交集：盈亏/情况类基准=期末 20260331 全集（train_5/68、train_6/84：交集 485 vs 答案 486 差 1 人判错）；流失/减少类基准=期初 20260101 全集（train_5/70：期初客户缺期末按 0 计流失，答案 120 行 vs 交集 119 行）（来源：答案对照裁决） |
