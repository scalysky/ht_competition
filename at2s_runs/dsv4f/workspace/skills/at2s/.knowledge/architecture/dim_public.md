# dim_public

## 表描述

- 表的业务含义：公共码表（通用代码字典），将各类编码字段的 code 翻译为中文描述，涵盖客户等级、客户状态、证件类型、风险类型、性别、学历、职业等。
- 数据粒度：一行 = 一个码值（`code`）在其所属码类型（`code_type_id`）下的描述。
- 每行代表什么：一个具体码值的中文含义。
- 可能的主键或唯一键：`code`（抽样唯一，155 行）。
- 日期字段和时间范围：无日期字段（静态码表）。
- 适合回答的业务问题：客户等级/状态/性别/学历/职业等码值的含义翻译；风险类型码值；证件类型码值。
- 使用时需要注意的限制：`describe` 存在少量中文断字（抽样显示如 `境外身份�` 结尾截断为显示问题，实际库内完整，见待确认）；同一 `code_type_id` 下 code 与 describe 一一对应；不同 code_type_id 下 code 前缀不同（100/200/300/400/500/600/700），可借此判断字段类型。

## 字段

| 字段名 | 数据类型 | 字段说明 | 示例或码值 | 来源 |
|---|---|---|---|---|
| code | character varying(12) | 码值，7 位数字 | 1000001 | 用户提供 |
| code_type_id | character varying(6) | 码类型编号，决定该码的含义域 | 100 | 数据推测 |
| describe | character varying(128) | 码值的中文描述 | 紫金理财钻石卡客户 | 用户提供 |

## 数据特征

- 抽样中发现的主要取值特征：`code_type_id` 共 7 类，各自的行数：100（6 行）、200（11 行）、300（58 行）、400（7 行）、500（5 行）、600（9 行）、700（59 行）。`code` 前 3 位与 code_type_id 相同（100xxxx 属于 100，依此类推）。
- 空值情况：全部字段 NOT NULL。
- 码值字段：`code` 与 `code_type_id` 均为码值型。
- 金额和数量字段：无。
- 日期字段：无。
- 客户、产品、机构等标识字段：无客户/产品/机构标识；`code` 用于关联各表码值字段。
- 可能影响聚合或关联的粒度问题：一行一码值，关联各表的码值字段（如 ads_cust_info_d.cust_lvl_cd / cust_status / gender_cd / edu_cd / prof_cd）为一对一补全，不会放大行数。

## 待确认

- 抽样输出中个别 `describe` 显示截断（如“境外身份�”），已用 hex 复核库内为完整 UTF-8（境外身份证），判定为显示伪影，但建议人工抽查个别码值。
- 1000006 客户等级描述为“空”的业务含义需人工确认。
