# dwd_cust_hold_d — 客户持有产品日事实

## 表描述

客户持有产品日事实表，408150 行（全库最大），覆盖 **90 个日期 `20260101`–`20260331`**，粒度 `(data_dt, pty_id, prdt_id, sys_source)` 唯一（ccy 由产品决定，不构成额外粒度）。（来源：数据推测）

持仓集中在普通账户人民币：nm+ccy='0' 占 358235 行；外币持仓少量（美元 270 行、港币 3095 行，全部在 nm 账户）。（来源：数据推测）

## 字段

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| data_dt | varchar(8) | 日期，`YYYYMMDD` 字符串 | 用户提供 |
| pty_id | varchar(32) | 客户号 | 用户提供 |
| prdt_id | varchar(12) | 产品ID，关联 `dim_product` | 用户提供 |
| sys_source | varchar(20) | 系统来源：普通(nm)、信用(fc) | 用户提供 |
| ccy | varchar(12) | 币种：0 人民币、1 美元、2 港币 | 用户提供 |
| hold_cnt | numeric(20,4) | 持有份额 | 用户提供 |
| mkt_val | numeric(20,4) | 持有市值。汇总滤币种与否**以题面为准**：明示币种才滤（如 ccy='2'），未提币种时全币种直接 SUM（用户确认，train_3 序号 43/51 裁决；详见 correlation.md ccy 条） | 用户提供 + 用户确认 |

## 别名与黑话

| 口语/黑话 | 库内准确值/字段 |
|---|---|
| 持有（时点） | 默认取**期末 20260331 单日**持仓快照；"期间任一日持有"仅在题目明示时使用（来源：用户确认，train_1 批次） |
| 仍持有 | 存在期末持仓行即算、**不滤 hold_cnt=0**（零份额清仓残留行计为持有；来源：答案对照裁决，train_5/75：19 行残留行被答案计入，"持有=份额>0"字面推理判错） |
| 持仓明细/集中度 | 按**原始持仓行**逐行判定与输出（不按 (pty_id,prdt_id) 跨账户 SUM 合并——nm/fc 双行各算一行、各自对总资产算占比；集中度分子=单行 mkt_val；来源：答案对照裁决，train_5/74） |
| 产品名单展示 | 名单类产品题（热度排名等）join dim_product 按 `(prdt_name, prdt_type_name)` 分组输出产品名+二级分类名+`COUNT(DISTINCT pty_id)` 持有客户数+`SUM(mkt_val)` 市值，不滤 ccy（来源：答案对照裁决，train_6/88）；不 join 快 4.4 倍但形态判错——形态正确优先 |
