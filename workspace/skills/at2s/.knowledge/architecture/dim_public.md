# dim_public — 标准化编码字典表

## 表描述

标准化编码字典表，155 行，7 个码表类型。**join 时必须同时给 `code` 和 `code_type_id` 两个条件**，同一 code 在不同类型下含义不同。（来源：数据推测）

各类型及在本数据集的使用情况（来源：数据推测）：

| code_type_id | 含义 | 条数 | 本数据集使用字段 |
|---|---|---|---|
| 100 | 客户等级 | 6 | `ads_cust_info_d.cust_lvl_cd` |
| 200 | 账户状态 | 11 | `ads_cust_info_d.cust_status` |
| 300 | 证件类型 | 58 | **未使用** |
| 400 | 风险等级（激进/积极/稳健/谨慎/保守…） | 7 | **未使用** |
| 500 | 性别（5000002 男 / 5000003 女） | 5 | `ads_cust_info_d.gender_cd` |
| 600 | 学历（6000002 博士 ~ 6000008 初中及其以下） | 9 | `ads_cust_info_d.edu_cd` |
| 700 | 职业（59 种，军人~其他专业技术人员） | 59 | `ads_cust_info_d.prof_cd` |

## 字段

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| code | varchar(12) | 标准字典码，7 位数字串 | 用户提供 |
| code_type_id | varchar(6) | 标准字典码类型，3 位数字串 | 用户提供 |
| describe | varchar(50) | 标准字典描述（中文明文） | 用户提供 |
