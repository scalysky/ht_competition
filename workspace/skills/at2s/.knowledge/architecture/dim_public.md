# dim_public — 标准化编码字典表

## 表描述
标准字典码表，每一行是一个"码类型 + 码值 + 含义"的映射。用于把各业务表中的代码字段翻译成可读含义。（来源：用户提供，来自 `表描述.sql` 的 COMMENT）

实测 `code_type_id` 取值为 `100`/`200`/`300`/`400`/`500`/`600`/`700` 六类（各类型码值条数：100→6、200→11、300→58、400→7、500→5、600→9、700→59）。各类型的含义由抽样 `describe` 归纳如下（数据推测，待确认）：

| code_type_id | 推测含义 | 典型码值 |
|---|---|---|
| 100 | 客户等级 | 1000001 紫金理财钻石卡客户 … 1000006 |
| 200 | 账户/客户状态 | 2000001 正常、2000002 冻结、2000003 挂失、2000004 销户、2000005 休眠已确认；另有 2000006~2000011 为跟进状态（首次接触/持续跟踪/紧密/放弃等） |
| 300 | 证件类型 | 3000001 身份证、3000002 军人身份证 … |
| 400 | 风险偏好类型 | 4000001 激进型 … 4000007 未知 |
| 500 | 性别 | 5000001 未知、5000002 男、5000003 女、5000004 非自然人、5000005 其他 |
| 600 | 学历 | 6000001 未知学历 … 6000009 其他 |
| 700 | 职业类型 | 7000001 军人 … 7000000+ 各类职业 |

## 字段
| 字段 | 类型 | 含义 | 来源 | 备注 |
|---|---|---|---|---|
| code | varchar(12) | 标准字典码 | 用户提供 | 与业务表代码字段同值 |
| code_type_id | varchar(6) | 标准字典码类型 | 用户提供 | 见上方类型映射（数据推测） |
| describe | varchar(50) | 标准字典描述 | 用户提供 | 码值含义 |

## 与其他表的关系
本表是被引用维表，通过 `code` 关联其它表的代码字段，并额外用 `code_type_id` 区分类型：
- `ads_cust_info_d.cust_lvl_cd` → `code`（type 100）
- `ads_cust_info_d.cust_status` → `code`（type 200）
- `ads_cust_info_d.gender_cd` → `code`（type 500）
- `ads_cust_info_d.edu_cd` → `code`（type 600）
- `ads_cust_info_d.prof_cd` → `code`（type 700）
> 关联时必须带 `code_type_id` 限制，否则不同类型码值可能撞码。（关系状态：推测）
