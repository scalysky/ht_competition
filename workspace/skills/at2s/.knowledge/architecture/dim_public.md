# dim_public

## 表描述

标准化编码字典表（用户描述）。静态字典，共 155 条，code 唯一（已验证无重复）（行数为数据推测）。用于把 ads_cust_info_d 等表中的码值字段翻译成中文含义。

## 字段

| 字段 | 类型 | 含义 | 来源 |
|---|---|---|---|
| code | varchar(12) | 标准字典码，7 位数字，**前 3 位 = code_type_id**（如 5000002 属于类型 500） | 用户描述（前缀规律为数据推测） |
| code_type_id | varchar(6) | 标准字典码类型。已确认映射：100=客户等级(6条)、200=账户状态(11条)、500=性别(5条)、600=学历(9条)、700=职业(59条)，分别对应 ads_cust_info_d 的 cust_lvl_cd / cust_status / gender_cd / edu_cd / prof_cd（已验证 0 缺失）。另有 300=证件类型(58条)、400=风险承受能力(7条)，在本数据集无对应字段 | 用户描述（类型含义映射为数据推测） |
| describe | varchar(50) | 标准字典描述（码值中文含义）。列名 `describe` 近似关键字，PostgreSQL 中可直接使用，跨方言时注意加引号 | 用户描述（列名注意为数据推测） |

## 用法示例（数据推测）

- 翻译客户等级：`JOIN dim_public p ON p.code = a.cust_lvl_cd AND p.code_type_id = '100'`
- code_type_id 条件可省略（code 本身已含类型前缀），但加上更稳妥。
