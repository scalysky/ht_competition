# dim_branch

> 表注释（`表描述.sql`）：**营业部表**

## ⚠ 源注释有缺陷，字段含义已由数据纠正

`表描述.sql` 中本表的 `COMMENT ON` 写错了：

- `org_id` 与 `org_name` 各被注释**两次**，第二次内容是"上级营业部/分公司 ID/名称"，覆盖了第一次
- `up_org_id`、`up_org_name`、`data_dt` **完全没有注释**

因此本表字段含义**不能照抄注释**。下表含义按数据实测判定，依据是：
`org_name` 取值全部以「营业部」结尾，`up_org_name` 取值全部以「分公司」结尾。

## 表描述

营业部维表，312 行，`data_dt` 仅 `20260531` 单值（单日快照）。

**自引用两层层级**：312 个 `org_id` 中仅 27 个出现在 `up_org_id` 里；
`up_org_id` 有 26/27（96.3%）能在本表 `org_id` 中找到，缺的 1 个推测为顶层机构。
