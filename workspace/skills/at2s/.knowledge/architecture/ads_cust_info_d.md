# ads_cust_info_d

## 表描述

客户信息表（用户描述）。按日的客户基本属性快照，每客户每日一行，粒度 (data_dt, pty_id) 唯一（数据推测，已验证无重复）。当前数据仅含 20260531 单日快照，共 500 名客户（数据推测）。

## 字段

| 字段 | 类型 | 含义 | 来源 |
|---|---|---|---|
| data_dt | varchar(8) | 日期，yyyymmdd 字符串；当前仅 20260531 | 用户描述（格式与取值为数据推测） |
| pty_id | varchar(32) | 客户号，格式 `C` + 15 位数字 | 用户描述（格式为数据推测） |
| sor_pty_id | varchar(32) | 经纪客户号，格式 `6666` + 15 位数字；与 pty_id 一一对应但格式不同 | 用户描述（格式为数据推测） |
| cust_lvl_cd | varchar(12) | 客户等级，码值 10000xx；含义经 dim_public(code_type_id=100) 翻译：1000001 紫金理财钻石卡、1000002 白金卡、1000003 金卡、1000004 银卡、1000005 紫金理财卡、1000006 空 | 用户描述（码值含义为数据推测，已比对字典） |
| cust_status | varchar(12) | 账户状态，码值 20000xx；经 dim_public(code_type_id=200) 翻译：2000001 正常、2000004 销户、2000005 休眠已确认（字典共 11 个值，数据仅出现这 3 个） | 用户描述（码值含义为数据推测，已比对字典） |
| cust_type | varchar(1) | 客户类型；当前数据全为 `P`（数据推测：P=个人客户）。注意：不在 dim_public 字典中，是字面值 | 用户描述（取值为数据推测） |
| prov_name | varchar(50) | 省份，中文名称非码值；高度集中：江苏省 478/500 | 用户描述（分布为数据推测） |
| city_name | varchar(50) | 城市，中文名称非码值；高度集中：苏州市 446/500，其次南京市 30 | 用户描述（分布为数据推测） |
| birth_dt | varchar(8) | 出生日期，yyyymmdd 字符串 | 用户描述（格式为数据推测） |
| cust_age | numeric(20,0) | 年龄（整数） | 用户描述 |
| name | varchar(40) | 姓名，已脱敏（如 `张**`） | 用户描述（脱敏为数据推测） |
| gender_cd | varchar(12) | 性别代码，经 dim_public(code_type_id=500) 翻译：5000002 男、5000003 女 | 用户描述（码值含义为数据推测，已比对字典） |
| edu_cd | varchar(32) | 学历代码，码值 60000xx，经 dim_public(code_type_id=600) 翻译（6000003 硕士、6000004 学士、6000005 大专、6000006 中专、6000007 高中、6000008 初中及其以下、6000009 其他） | 用户描述（码值含义为数据推测，已比对字典） |
| prof_cd | varchar(100) | 职业类型编码，码值 70000xx，经 dim_public(code_type_id=700) 翻译（59 个职业码，如 7000031 公职离/退休、7000032 非公职离/退休、7000041 自由职业者） | 用户描述（码值含义为数据推测，已比对字典） |
| org_id | varchar(100) | 所属营业部ID，格式 `XX` + 8 位数字；与 dim_branch.org_id 关联（500/500 全部匹配） | 用户描述（格式与关联验证为数据推测） |
