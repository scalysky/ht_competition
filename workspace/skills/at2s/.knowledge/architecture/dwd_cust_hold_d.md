# dwd_cust_hold_d — 客户持有产品日事实

## 表描述

客户持有产品日事实表，408150 行（全库最大），覆盖 **90 个日期 `20260101`–`20260331`**，粒度 `(data_dt, pty_id, prdt_id, sys_source)` 唯一（ccy 由产品决定，不构成额外粒度）。（来源：数据推测）

持仓集中在普通账户人民币：nm+ccy='0' 占 358235 行；外币持仓少量（美元 270 行、港币 3095 行，全部在 nm 账户）。（来源：数据推测）

## 字段

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| data_dt | varchar(8) | 日期，`YYYYMMDD` 字符串 | 用户提供 |
| pty_id | varchar(32) | 客户号 | 用户提供 |
| prdt_id | varchar(12) | 产品ID，关联 `dim_product` | 用户提供 |
| sys_source | varchar(20) | 系统来源：普通(nm)、信用(fc) | 用户提供 |
| ccy | varchar(12) | 币种：0 人民币、1 美元、2 港币 | 用户提供 |
| hold_cnt | numeric(20,4) | 持有份额 | 用户提供 |
| mkt_val | numeric(20,4) | 持有市值（推测为对应币种计价，汇总前须过滤币种） | 用户提供 + 数据推测 |
